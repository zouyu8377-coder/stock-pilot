# 决策分析与任务交接

## 工作台

- 账户调整建议说明行动、账户影响、触发条件，并关联同主题或同标的核查任务。
- 执行清单区分 Agent 取证、用户补充、条件监控；已取得证据不等于已更新建议。
- AI 机会与雷达以方向 ID、代表标的、规范化名称去重，不为填满列表重复展示。
- 手动巡检在剩余取证预算内执行本轮新任务；取得完整结果且还有模型预算时最多追加一次复核。否则结果留存，后续分析使用。

## 外部模型

1. 展开工作台“外部分析”，生成请求。此动作刷新本地上下文，但不调用模型。
2. 复制提示词或下载文件，主动交给外部模型。内容包含敏感账户和交易事实。
3. 模型只返回 JSON：`request_id`、`snapshot_fingerprint`、`review`。
4. 粘贴或上传返回文件，校验并预览，确认后进入同一建议、任务、复盘记录。

请求也保存在 `backend/data/agent_exchange/exchange-*.json`，本地协作工具可读取其 `prompt` 字段，写出结果 JSON，再由用户在网页导入。首版没有文件监听器或无确认自动导入。

## 校验边界

- 4小时有效期；账户快照变化、最新分析变化、证据指纹不符均拒绝导入。
- 必须先预览同一份结果，再确认；相同请求重复确认不重复登记任务。
- 复用内置证据引用、账户风险限制和建议校验，不允许外部模型创造未验证的证据引用。
- 新公开来源应作为待核查任务，不直接升级为事实。
- 导入不执行代码，不修改持仓，不执行交易。模型身份标记为外部用户提交，不声称验证了实际提供方。
